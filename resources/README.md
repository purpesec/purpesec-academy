# Recursos compartidos

[Inicio](../README.md)

Esta carpeta queda reservada para material complementario que pueda reutilizarse en más de una ruta.

## Contenido previsto

| Carpeta | Propósito | Estado |
|---|---|---|
| `cheatsheets/` | Referencias rápidas de herramientas y comandos | Planificado |
| `wordlists/` | Diccionarios pequeños creados para los laboratorios | Planificado |
| `tools/` | Scripts auxiliares reutilizables | Planificado |

## Reglas

- No subir binarios grandes, dumps de memoria ni imágenes de máquinas virtuales.
- No incluir malware real, credenciales o datos personales.
- Indicar la fuente y licencia de cualquier recurso externo.
- Mantener junto a cada recurso una explicación de su uso.
