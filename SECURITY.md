# Seguridad

Este repositorio contiene código y configuraciones vulnerables de forma intencional para fines educativos.

## Qué reportar

Reporta exposición accidental de secretos, dependencias comprometidas, archivos maliciosos no simulados o cualquier riesgo que afecte a quienes clonen el repositorio.

No es necesario reportar como vulnerabilidad el comportamiento inseguro que un laboratorio identifica expresamente como parte del ejercicio.

## Cómo reportar

No publiques secretos ni muestras peligrosas en un issue. Utiliza el canal privado de reporte de seguridad del proveedor donde esté alojado el repositorio. Si no está disponible, contacta de forma privada al responsable del repositorio.

Incluye el archivo afectado, el impacto, los pasos de reproducción seguros y una propuesta de mitigación cuando sea posible.
