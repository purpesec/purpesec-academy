# Privilege Escalation

[Inicio](../README.md) | [Configurar laboratorio](../setup/README.md)

Ruta prevista para estudiar enumeración local y escalada de privilegios en Linux y Windows dentro de máquinas de laboratorio.

## Estado

Planificado. Todavía no hay sesiones publicadas.

## Alcance previsto

- Enumeración local de usuarios, grupos, servicios y permisos.
- Configuraciones inseguras en Linux: `sudo`, SUID, tareas programadas y capabilities.
- Configuraciones inseguras en Windows: servicios, registro, tokens y políticas de instalación.
- Validación manual de hallazgos producidos por herramientas de enumeración.
- Mitigación y documentación del riesgo.

## Prerrequisitos previstos

- Administración básica de Linux y Windows.
- Reconocimiento y enumeración de sistemas.
- Uso de una terminal y lectura de permisos.
